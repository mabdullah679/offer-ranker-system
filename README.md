# Offer Ranker System

This repo contains a small end-to-end ML system:

- `api/` – FastAPI + scikit-learn inference service deployed to Google Cloud Run.
- `training/` – (planned) customer upsell training & evaluation workflow.
- `data-quality/` – (planned) YAML-driven data quality CLI that gates all data.

For details on the live API, see [`api/README.md`](api/README.md).
